API JSON DOCUMENTATION
- These are the JSON structures for Add/Update APIs of the core resources. GET methods return the same structure as well.
- Status values are still changeable and not finalized yet.
- All Id fields can be excluded but not in PUT requests because it is used to identify the object being modified.

Core API Endpoint: /admin

Other endpoints:
GET /admin/{resource} - Retrieves all records of the specified resource in a list
POST /admin/{resource}/add - Create a new resource
GET /admin/{resource}/{id} - Returns a specific resource by its ID
PUT /admin/{resource}/{id} - Updates an existing resource by its ID

GET /admin/dashboard - Returns global dashboard stats

Resources:
accounts - manage admin accounts
terms - manage terms
programs - manage programs
courses - manage courses
students - manage students
faculty - manage faculty
schedules - manage schedules
sections - manage sections
departments - manage department labels

debugging:
GET /admin/facultyentity - Returns all faculty entities (debugging endpoint)

------------------------------------------------
BEHAVIOR OF /admin/{resource} 
For each resource endpoint under /admin/{resource}:

GET /admin/{resource} returns a result object with:
- a filtered list of matching items
- summary stats computed from the same search filters

Search is controlled by optional query params specific to each resource.
- If no filters are passed, the endpoint returns all items.
- If filters are passed, the list and stats are both based on those filters.

The stats counts are derived from the same query conditions as the list, so they reflect the same search result set.

----------------------------------------------
STATS AVAILABLE PER RESOURCE

Every GET /admin/{resource} response includes a `stats` object with summary values computed from the same filter set as the returned list.

Available resource-level stats:
- GET /admin/courses
  - totalCourses
  - totalActiveCourses
  - totalInactiveCourses
- GET /admin/students
  - totalStudents
  - totalActiveStudents
  - totalIrregularStudents
  - totalGraduatedStudents
- GET /admin/faculty
  - totalFaculty
  - totalActiveFaculty
  - totalInactiveFaculty
  - totalSchedulesAssignedPerFaculty
- GET /admin/schedules
  - totalSchedules
  - totalActiveSchedules
  - totalInactiveSchedules
  - weeklyHours
  - dailyHours
- GET /admin/sections
  - totalSections
  - totalActiveSections
  - totalInactiveSections
  - totalEnrolledStudentsPerSection

Resources that currently do not return per-resource stats in the list endpoint:
- accounts
- terms
- programs
- departments

For global dashboard totals use GET /admin/dashboard:
- totalPrograms
- totalCurriculums
- totalCourses
- totalSections
- totalStudents
- totalFaculty
- totalSchedules
- totalDepartments
- totalAdminAccounts

----------------------------------------------
FILTERING/SEARCH CAPABILITIES:

GET /admin/programs?title={title}&status={status}
- title: optional, partial name match (case-insensitive)
- status: optional, ACTIVE or INACTIVE

GET /admin/courses?title={title}&department={departmentId}&program={programId}&curriculum={curriculumId}&yearLevel={yearLevel}&semester={semester}&status={status}
- title: optional, partial name match (case-insensitive)
- department: optional, department ID
- program: optional, program ID
- curriculum: optional, curriculum ID
- yearLevel: optional, year level
- semester: optional, semester number
- status: optional, ACTIVE or INACTIVE

GET /admin/students?name={name}&studentStatus={studentStatus}&scholasticStatus={scholasticStatus}&program={programId}&curriculum={curriculumId}&academicYear={academicYear}&yearLevel={yearLevel}&section={sectionId}
- name: optional, partial name match (case-insensitive, searches first + middle + last name)
- studentStatus: optional, ACTIVE, INACTIVE, GRADUATED, or DROPPED
- scholasticStatus: optional, REGULAR or IRREGULAR
- program: optional, program ID
- curriculum: optional, curriculum ID
- academicYear: optional, academic year string (e.g., "2025-2026")
- yearLevel: optional, year level
- section: optional, section ID

GET /admin/faculty?name={name}&status={status}&department={departmentId}&employmentType={employmentType}&qualifiedCourse={qualifiedCourseId}&scheduledCourse={scheduledCourseId}
- name: optional, partial name match (case-insensitive, searches first + middle + last name)
- status: optional, ACTIVE or INACTIVE
- department: optional, department ID
- employmentType: optional, FULL_TIME or PART_TIME
- qualifiedCourse: optional, course ID
- scheduledCourse: optional, course ID //filters through courses that are scheduled

GET /admin/schedules?academicYear={academicYear}&program={programId}&curriculum={curriculumId}&yearLevel={yearLevel}&semester={semester}&section={sectionId}&status={status}&day={day}
- academicYear: optional, academic year string
- program: optional, program ID
- curriculum: optional, curriculum ID
- yearLevel: optional, year level
- semester: optional, semester number
- section: optional, section ID
- status: optional, ACTIVE or INACTIVE
- day: optional, day name

GET /admin/sections?name={name}&program={programId}&yearLevel={yearLevel}&status={status}
- name: optional, partial name match (case-insensitive)
- program: optional, program ID
- yearLevel: optional, year level
- status: optional, ACTIVE or INACTIVE

GET /admin/departments?name={name}
- name: optional, partial name match (case-insensitive)

API JSON DOCUMENTATION
- These are the JSON structures for Add/Update APIs of the core resources. GET methods return the same structure as well.
- Status values are still changeable and not finalized yet.
- All Id fields can be excluded but not in PUT requests because it is used to identify the object being modified.

Core API Endpoint: /admin

Other endpoints:
GET /admin/{resource} - Retrieves all records of the specified resource in a list
POST /admin/{resource}/add - Create a new resource
GET /admin/{resource}/{id} - Returns a specific resource by its ID
PUT /admin/{resource}/{id} - Updates an existing resource by its ID

Resources:
accounts - manage admin accounts
terms - manage terms
programs - manage programs
courses - manage courses
students - manage students
faculty - manage faculty
schedules - manage schedule
sections - manage section
